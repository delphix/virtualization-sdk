# Breaking Changes - v.5.1.0

## New Required Schema: virtualToPhysicalDefinition
The `schema.json` must now define a `virtualToPhysicalDefinition` schema. This schema defines the user-facing parameters for the `source_to_physical` operation.

See [VirtualToPhysicalDefinition](../../References/Schemas_and_Autogenerated_Classes.md#virtualtophysicaldefinition) for details on how to define this schema.
